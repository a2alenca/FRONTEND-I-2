## Descripción

Sitio web interactivo tipo catálogo de videojuegos desarrollado con React y Vite. Utiliza Bootstrap 5 y estilos CSS personalizados para el diseño responsivo.

### Funcionalidades principales
- Catálogo de productos cargado desde un archivo local (`productos.json`).
- Filtro de juegos por categoría en tiempo real.
- Carrito de compras funcional (agregar productos, eliminarlos individualmente, vaciar carrito y cálculo del total).
- Formulario para agregar nuevos juegos al catálogo con validación de campos.
- Botón para eliminar productos de la tienda.
- Formulario de contacto con validación de nombre, correo y longitud del mensaje.

---

## Tecnologías utilizadas

- HTML5 y CSS3 (CSS Grid y Flexbox)
- Bootstrap 5.3
- JavaScript (ES6)
- React 18 + Vite
